# TxT — настольное приложение для Windows

TxT теперь можно собрать как настольную программу для Windows с установщиком.

## Что нужно для сборки

Сборка установщика выполняется **на Windows** (или через GitHub Actions, см. ниже). Из этого окружения собрать Windows-установщик нельзя, но проект полностью настроен и готов к сборке.

## Способ 1. Сборка на вашем Windows-компьютере

### 1. Установите необходимые инструменты

- **Node.js** (версия 18 или новее) — https://nodejs.org
- **Rust** — установите с https://rustup.rs (запустите скачанный файл и следуйте инструкциям)
- **Microsoft Visual C++ Build Tools** — скачайте с сайта Microsoft и установите компонент «Desktop development with C++»
- **WebView2** — обычно уже установлен на Windows 10/11; если нет, скачайте с сайта Microsoft

### 2. Соберите программу

Откройте папку проекта в терминале и выполните:

```
npm install
npm run tauri:build
```

После завершения готовые установщики будут в папке:

- **`src-tauri/target/release/bundle/nsis/TxT_0.1.0_x64-setup.exe`** — обычный установщик (рекомендуется)
- **`src-tauri/target/release/bundle/msi/TxT_0.1.0_x64_en-US.msi`** — MSI-установщик для корпоративного использования

### 3. Установите программу

Запустите скачанный `.exe` файл — программа установится в систему и появится в меню «Пуск».

## Способ 2. Автоматическая сборка через GitHub Actions

Если вы загрузите проект на GitHub, сборка установщика запустится автоматически:

1. Загрузите проект в репозиторий на GitHub.
2. Создайте тег версии: `git tag v0.1.0 && git push origin v0.1.0`
3. GitHub Actions автоматически соберёт установщик и прикрепит его к черновику релиза.
4. Зайдите на страницу репозитория → «Releases» → найдите черновик релиза → скачайте `.exe` установщик.

Также можно запустить сборку вручную: вкладка «Actions» → «Build TxT for Windows» → «Run workflow».

## Как работает программа

- Программа открывается в отдельном окне с тёмной темой (как GitHub).
- Подключается к той же базе данных, что и веб-сайт.
- Вход, редактирование разделов и живые обновления работают точно так же.
- Нужен интернет для подключения к базе данных.
